# Procurement Approval Policy

## Purpose

This policy sets the approval authority required to commit Harbourline
Freight Systems to spend with a vendor or supplier, and the additional
review required before onboarding a new vendor.

## Approval thresholds

Procurement approval is tiered by the total value of the commitment. Spend
under $5,000 can be approved by the requester's manager. Spend from $5,000
up to $25,000 requires department head approval. Spend from $25,000 up to
$100,000 requires CFO approval. Any commitment above $100,000 requires board
approval before a purchase order is raised.

| Spend | Approver |
|---|---|
| Under $5,000 | Manager |
| $5,000–$25,000 | Department head |
| $25,000–$100,000 | CFO |
| Above $100,000 | Board |

## Raising a request

Procurement requests are raised through the Finance Portal, which routes the
request to the correct approver automatically based on the estimated total
value. Requests that span multiple approval tiers, for example a
multi-year contract, are assessed on the full contract value rather than
the first year's spend alone.

## New vendor onboarding

Any new vendor being onboarded to handle Harbourline customer data must pass
a security review before the first purchase order is issued, regardless of
the spend tier that vendor's contract falls into. The security review is
coordinated between Finance and the engineering security function and must
be completed before contract signature.

## Existing vendors

Renewals and additional orders with an already-approved vendor follow the
same threshold table above, but do not require a repeat security review
unless the vendor's access to customer data materially changes.
